URL Shortener API

A backend API for creating and managing short links, built with Node.js, Express, and a MongoDB replica set. Short codes come from an atomic Base62 counter, so they never collide. Redirects are cached in Redis and never wait on analytics, which are collected in batches by BullMQ workers and broken down by country, referrer, and date.

Sign up and get a token with POST /api/auth/register and POST /api/auth/login, then create links with POST /api/shorten.
